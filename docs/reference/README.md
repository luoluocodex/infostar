## 使用规则

1. **只读**：本目录文件不修改、不重命名；如需提取文本，请用中间目录（如 `.workbuddy/_ref/`，已 gitignore）。
2. **判题以官方答案为准**：程序阅读题的标准输出以 `答案.docx` 为基准，并与引擎交叉验证。
3. **优先改编**：入库题目优先标 `adapted`（改编），保留真题思维价值的同时改数值 / 改情境 / 补图形。
4. **可追溯**：`adapted` 题必须写清原题出处与改编说明（见题库规范的 `source` 字段）。
