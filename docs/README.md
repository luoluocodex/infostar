## 阅读顺序建议

> 动手改本仓库前，先读根目录 [`../AGENTS.md`](../AGENTS.md)（仓库级协作规约与硬性约束）。

**第一次接手项目** → 根目录 [README](../README.md) → `plan/` 主方案（§1–§5 快速过）→ `guides/01` 结构 → `guides/04` MVP 规格。

**要动手写代码** → `guides/01` 结构 → `guides/03` 题库规范 → `plan/` §6–§8。

**要部署上线** → `guides/02` 部署指南 → `plan/` §9。

**要出题** → `guides/03` 题库规范 + `guides/05` 术语表 → `guides/04` 作为范例。
