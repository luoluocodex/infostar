## 1. 顶层结构

```
infostar/
├─ README.md              # 项目总览、快速开始、文档导航
├─ CHANGELOG.md           # 版本记录
├─ .gitignore             # 忽略规则（node_modules / dist / 中间产物）
├─ docs/                  # 全部文档（方案 / 原始资料 / 指南）
├─ src/                   # 前端源码（Phase 0 起）
├─ public/                # 静态资源（PWA 图标、插画）
├─ Dockerfile             # 多阶段构建：node build → nginx:alpine
├─ docker-compose.yml     # 单容器编排（绑 127.0.0.1:8081）
├─ nginx.conf             # 容器内 nginx 配置（含安全头、路由回退）
├─ vite.config.ts
├─ tailwind.config.ts
└─ package.json
```

## 3. 前端源码结构 `src/`（Phase 0 起落地）

```
src/
├─ main.tsx                 # 入口：挂载 React、注册 SW（仅 https）
├─ App.tsx                  # 路由表 + 全局布局（安全区、竖屏）
├─ routes/                  # 页面级组件
│  ├─ MapPage.tsx           # 闯关地图（主页）
│  ├─ LevelPage.tsx         # 关卡游玩页（五段式流程）
│  ├─ ResultPage.tsx        # 星级结算页
│  ├─ ReviewPage.tsx        # 错题本 / 重练（Phase 3）
│  ├─ ReportPage.tsx        # 学习报告（Phase 4）
│  └─ SettingsPage.tsx      # 设置 / 存档导出导入
├─ engine/                  # 纯逻辑，无 UI 依赖，必须可单测
│  ├─ cpp/                  # C++ 子集解释器
│  │  ├─ lexer.ts           # 词法分析
│  │  ├─ parser.ts          # 递归下降语法分析
│  │  ├─ ast.ts             # AST 类型定义
│  │  ├─ interpreter.ts     # 解释执行 → 生成 Frame Trace
│  │  ├─ types.ts           # Frame / VarSnapshot / 类型语义
│  │  └─ errors.ts          # 儿童化错误消息
│  ├─ blocks/               # 拖拽积木
│  │  ├─ blockModel.ts      # 积木数据模型
│  │  ├─ slots.ts           # 槽位定义与类型校验
│  │  └─ validate.ts        # 静态合法性检查
│  └─ grade.ts              # 判分与星级计算
├─ components/
│  ├─ viz/                  # 可视化组件（VarBox / ArrayGrid / Matrix2D /
│  │                        #   StdoutTyper / LoopDial / CondFork / StackView / QueueView）
│  ├─ blocks/               # BlockTray / DropSlot / CodeSkeleton
│  ├─ runner/               # TracePlayer（播放器）/ CodeHighlighter
│  └─ common/               # 按钮、卡片、星星、弹窗等通用件
├─ content/                 # 题库（按区域拆包，动态 import）
│  ├─ regionA_numbers/      # A 区：数数里的秘密
│  ├─ regionB_geometry/     # B 区：图形与生活
│  ├─ regionC_thinking/     # C 区：思维训练营
│  ├─ regionD_cpp/          # D 区：C++ 语句村
│  ├─ regionE_algorithms/   # E 区：算法剧场
│  ├─ regionF_pastpapers/   # F 区：真题擂台
│  └─ schema.ts             # Zod 题库 Schema + 构建期校验入口
├─ store/                   # Zustand 状态
│  ├─ progress.ts           # 进度、星级、连击
│  ├─ settings.ts           # 设置项
│  └─ db.ts                 # Dexie（IndexedDB）定义
├─ i18n/zh.ts               # 全部中文文案集中管理
└─ styles/                  # tokens.css（设计令牌）、动画
```

**分层铁律**

1. **`engine/` 不 import UI**：纯函数、纯数据，可在 Node 下单测（Vitest）。
2. **`content/` 不 import `components/`**：题库只是数据。
3. **文案不出现在组件里**：一律走 `i18n/zh.ts`。
4. **可视化组件只读 `Frame`**：不自己算程序逻辑。

## 4. 命名与编号约定

| 对象 | 规则 | 示例 |
|---|---|---|
| 关卡 ID | `^[A-F]\d{2}-\d{2}$`（区域字母 + 章节 2 位 + 序号 2 位） | `C01-05`、`D01-03` |
| 章节目录 | `regionX_<英文主题>` | `regionD_cpp` |
| 题库文件 | 一章一文件 | `C01_recursion.ts` |
| React 组件 | PascalCase，文件名同组件名 | `VarBox.tsx` |
| 纯逻辑模块 | camelCase | `interpreter.ts` |
| 中文文档 | 数字前缀 + 中文名 | `03-内容与题库规范.md` |
| 代码/配置文件名 | 英文 | `vite.config.ts` |
| 角色名 | 统一「小明 / 小红」，避免混用 | — |

## 5. 常见任务该改哪里

| 我要… | 改哪里 |
|---|---|
| 加一道题 | `src/content/regionX.../*.ts`，按 `guides/03` 规范；再跑 `npm run validate:content` |
| 加一种题型 | `content/schema.ts`（枚举）+ 新组件 `components/`，并在 `guides/03` 补 payload 说明 |
| 改一个可视化动画 | `components/viz/*` |
| 改引擎支持的语法 | `engine/cpp/*` + 同步更新 `guides/03` 的语法白名单 + 补单测 |
| 改部署方式 | `Dockerfile` / `docker-compose.yml` / `nginx.conf` + 同步 `guides/02` |
| 改 UI 文案 | `i18n/zh.ts`（不要在组件里硬编码） |
