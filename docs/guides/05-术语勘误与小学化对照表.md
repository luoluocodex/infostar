## 1. 考纲原文勘误（留痕）

考纲与素材中存在以下笔误，本项目**统一采用正确口径**，并把勘误记录在案，避免后续有人「照考纲抄错」。

| 出处 | 原文 | 问题 | 本项目口径 |
|---|---|---|---|
| 考纲 · 语句部分 | 「6、**输出**语句 cin」 | `cin` 是**输入**语句 | **`cin` = 输入语句** |
| 考纲 · 语句部分 | ⑤⑥ 都写「输出语句」 | 重复笔误 | ⑤ = `cout`（输出），⑥ = `cin`（输入） |
| 考纲 · 排序算法 | 「**选大**排序、插入排序、冒泡排序」 | 应为「**选择**排序」 | **选择排序** |
| `C++训练题.doc` 改错题 | `#inlude` / `iostram` / `maln()` / `For` / `If` | 改错题的**刻意错误** | **保留原样**，作为「找 Bug」题型素材 |
| 考纲 · 参考书 | 《小学生 c++ 编程入门》 | 大小写不统一 | 写作《小学生 C++ 编程入门》（清华大学出版社） |

## 2. 技术术语 → 给孩子看的说法

### 2.1 语句与数据类型

| 技术术语 | 给孩子看的说法 |
|---|---|
| 变量 | 会变的盒子 |
| 变量名 | 盒子上的标签 |
| 赋值 `a=5` | 把 5 放进盒子里 |
| 数据类型 | 盒子的型号 |
| `int` | 小号盒子（装整数） |
| `long` | 大号盒子（装很大的整数） |
| `float` / `double` | 能装小数点的盒子 |
| 溢出 | 盒子太小装不下，爆开了 |
| 常量 | 焊死的盒子，里面的东西不能换 |
| `++` / `--` | 电梯上升一层 / 下降一层 |
| `cout` | 对着话筒念出来 |
| `cin` | 收到别人递来的一张纸条 |
| `endl` | 念完换一行 |
| 主程序 `main` | 房间的正门，从这儿进去 |
| `#include <iostream>` | 先拿出工具箱 |
| `return 0;` | 走出房间，报告「一切正常」 |

### 2.2 条件、循环与数组

| 技术术语 | 给孩子看的说法 |
|---|---|
| 条件判断 | 岔路口 |
| `if` | 如果……就…… |
| `else` | 否则 |
| `>` `<` `==` | 比大小、看一样不一样 |
| 逻辑运算符 `&& \|\| !` | 「又……又……」「或者」「不是」 |
| 循环 | 转圈圈 |
| `for` | 一圈一圈地做，数着圈数做 |
| 循环变量 `i` | 计数的小手指 |
| 嵌套循环 | 大圈里套小圈 |
| 数组 | 一排储物柜 |
| 下标 / 索引 | 柜子编号 |
| 一维数组 | 一排柜子 |
| 二维数组 | 电影院的座位表（几排几号） |
| `a[i]` | 第 i 号柜子里的东西 |

### 2.3 算法与数学

| 技术术语 | 给孩子看的说法 |
|---|---|
| 算法 | 一步步做事的方法 |
| 顺序查找 | 一本一本翻书找 |
| 二分查找 | 猜数字，一次砍一半 |
| 排序 | 排队 |
| 选择排序 | 每次挑最矮的站前面 |
| 插入排序 | 整理手里一把扑克牌 |
| 冒泡排序 | 泡泡大的往上浮 |
| 枚举 | 一个一个试（试开密码锁） |
| 递推 | 一步一步往上爬（后面靠前面推出来） |
| 队列 | 排队伍买奶茶（先来先买） |
| 栈 | 叠盘子（最后放的先拿走） |
| 入队 / 出队 | 排到队尾 / 队头的人走掉 |
| 入栈 / 出栈 | 放上一个盘子 / 拿走最上面的盘子 |
| 遍历 | 从头到尾走一遍 |
| 取余 `%` | 剩下没分完的 |
| 整除 `/` | 能整份分出去的 |
| 周期 | 转圈圈回到原处（星期几） |
| 进制 | 只用几个数字数数（如只会 0/1/2 的外星人） |
| 容斥 | 两个圈重叠的地方 |
| 最值 | 最大 / 最小 |
| 分数 | 切蛋糕，切出几分之几 |
| 比例 | 两种东西的倍数关系 |
| 编译 | 把话翻译给电脑听 |

## 3. 写作口径规则

1. **不出现技术黑话**：`时间复杂度`、`算法复杂度`、`数据结构`、`递归`、`指针`、`函数调用栈` 等一律换成生活化表达。
2. **先具体后抽象**：先讲「20 颗糖分给 3 个人」，再写 `20 % 3`，最后才出现符号。
3. **一句话只讲一件事**：单句 ≤ 25 字为宜（小学五/六年级阅读习惯）。
4. **正向温和**：错误反馈不说「错」，说「再想想」「就差一点点」；不用红色叉号大图标，用轻提示。
5. **角色统一**：只用「小明 / 小红」；不混用「小刚」「东东」等。
6. **单位与数字**：数字与单位间加空格（`20 颗`），避免 `20颗` 贴在一起读起来费劲。
7. **不用 emoji 当正文**（可少量用于按钮/图标，图内）。

## 4. UI 文案示例（可直接用）

| 场景 | 推荐文案 | 避免 |

| 进入关卡 | 我们来玩一关吧 | 开始答题 |
